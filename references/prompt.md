# 双栏批注网页生成提示词（完整版）

每次生成 HTML 前，将以下要求逐条落实。这是产出的验收标准，不是参考。

## 提示词正文

将以下学术论文制作成一个完整的双栏批注 HTML 文件，重点呈现论文的论证结构与逻辑层次。

【文件要求】
输出单个 .html 文件，包含以下结构：

1. 顶部导航栏
   - 标题：论文名 + 来源信息（期刊 / 年份 / DOI / 作者，有多少写多少）
   - 颜色图例，对应以下分析维度：
     • 黄色 = 核心论点/thesis
     • 红色 = 关键概念/术语
     • 蓝色 = 实证证据/数据
     • 绿色 = 让步/反驳处理
     • 紫色 = 方法论说明

2. 章节导航条（sticky，可跳转各节）

3. 主体内容：左右双栏布局

   左栏：英中双语对照
   • 每段按以下顺序呈现：
     ① 英文原文（Lora 衬线字体，按五类维度高亮标注关键内容）
     ② 中文译文（紧接在英文段落下方，浅米色背景块 + 左侧细竖线，与英文区分）
        - 意译为主，读起来像中文学术论文
        - 不逐字直译，保持中文表达流畅
        - 不加颜色高亮，保持干净
   • 英中之间用 1px 细分隔线隔开

   右栏：中文批注（逐段对应）
   • 每段批注包含：
     ① 段落功能（如：引出问题/提供证据/反驳异议/总结）
     ② 逻辑角色（该段在整体论证链中的位置）
     ③ 值得注意的论证技巧或潜在漏洞

4. 底部论证结构总览
   - 全文逻辑骨架（问题→论点→方法→证据→反驳/让步→结论）
   - 作者核心主张一句话版本
   - 论证最强处 vs 最弱处各一条

【设计风格】
- 深海军蓝导航栏 + 米白纸张底色
- 五类维度分色高亮
- 字体：正文 Lora，界面 IBM Plex Sans（本地无此字体时用系统衬线/无衬线优雅降级，不得依赖外部 CDN）
- 中文译文块：浅米色背景（#f0ece2）+ 左侧细竖线，与英文原文视觉区分，同属左栏
- 批注卡片：左色边 + 浅背景
- 响应式（移动端单栏）

【补充要求】
1. 所有直接引用的原句，必须逐字来自论文，不得改写；关键数据请标注其所在章节。
2. 若论文过长，先输出全文目录，再按章节分批生成，不要省略任何一节。
3. 右栏的「潜在漏洞」必须给出具体依据（哪句话、哪个数字、哪处不一致），不要写泛泛而谈的批评。

## 使用方法

- 短论文（≤20 页）：一次性按上述要求生成完整 HTML。
- 长论文（>20 页）：先向用户展示完整章节目录；再按章节分批生成内容，逐节写入同一个 HTML 文件；全部写完后核对节数与目录一致。
- 样式细节（CSS 变量、组件类名、布局断点）见 `html-spec.md`，务必与其保持一致。
